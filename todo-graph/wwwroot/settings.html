Настройки проекта

Здесь настраиваются имя пользователя и локальные GitLab MCP-процессы для фонового чтения MR и подтверждённых действий.

Пользователь

Только чтение

GitLab MCP

Нужен для получения состояния, source branch и новых комментариев MR.

Только подтверждённые действия

GitLab MCP Write

Используется только после подтверждения ответа человеком и для создания MR после ручного push.

Только чтение

GitHub MCP

Нужен для чтения состояния, исходной ветки и новых комментариев GitHub PR. Push и создание PR остаются за пользователем.

Безопасность и push

Токены шифруются на этом компьютере и не возвращаются в браузер. На write MCP разрешаются только перечисленные точные tools; инструменты push, commit и работы с ветками запрещены. Push ветки выполняет только человек.
