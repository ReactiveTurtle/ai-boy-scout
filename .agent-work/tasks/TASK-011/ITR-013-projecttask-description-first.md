## Expected result

Project owns its ProjectTask entities. TodoGraph API creates a task from Description alone and lists that Project's tasks; new tasks have no Title until a Process stage supplies one.

## Scenarios

1. `POST /api/projects/{projectId}/tasks` with `{ description }` creates a child ProjectTask with a GUID, null Title, and the supplied description.
2. `GET /api/projects/{projectId}/tasks` returns that Project's tasks; an unknown Project returns 404.
3. Blank descriptions are rejected with HTTP 400 and do not add a child.
4. Process output can set/replace Title and Description; a missing Title leaves the current Title unchanged.
5. Creating a task does not start a Process; a Process is selected explicitly in a later action.
6. Applying process output preserves the ProjectTask ID and its parent Project relationship.

## In scope

- Add ProjectTask as an entity owned inside the Project aggregate.
- Add description-only task creation and a domain method for Process updates.
- Keep Title nullable until generated by a Process stage.
- Add Application CQRS command/query handlers, EF owned-entity mapping/migration, and minimal API endpoints for create/list.

## Out of scope

- Process selection/start, stage snapshots/hash storage, SignalR task events, and UI.

## YAGNI constraint

- Do not add property-mirroring unit tests; verify the behavior through a temporary API/database scenario instead.

## Verification result

- Added `ProjectTask` as an owned child of `Project`; it starts with `Title = null` and required Description. Domain supports Process updates to either field without changing task identity.
- Added Application CQRS create/list handlers, EF owned-task mapping with migration `AddProjectTasks`, and minimal API routes.
- Full solution Release build to temporary output passed with 0 warnings/errors.
- Operational API check with isolated `TODO_GRAPH_DB`: project/task creation returned GUID IDs; GET task list returned the task; blank description returned 400; unknown project returned 404; after API restart the task remained persisted with Title still null.
- No new unit tests were added per YAGNI direction. Process selection/snapshot/execution remains out of scope for this iteration.
