## Expected result

A ProcessStage can pause a ProcessRun with a prompt, accept free-text input, and resume that same stage without creating another ProcessRun.

## User decision

The user chose prompt + free-text response and resuming the same stage.

## Out of scope until implementation

- UI/API delivery of the prompt and response, persistent runtime state, and AI invocation.
