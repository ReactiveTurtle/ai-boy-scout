# ITR-005 - Build the Russian triage desk

Status: verifying

## Expected result

The user works in a fully Russian, distinctive interface that clearly separates raw notes, AI review, and implementation-ready tasks.

## In scope

- Russian product copy and document metadata;
- note and task workspaces;
- AI proposal review, confirmation, and retry;
- two-state filters and task completion;
- responsive desktop and mobile layout;
- a non-template visual system.

## Out of scope

- editing AI drafts;
- task priorities, assignees, and deadlines;
- drag and drop;
- MCP task tools.

## Primary risk

A visually unusual interface could obscure the workflow or become unusable on narrow screens.

## Decision

Use a workshop/dispatch-board visual language with an explicit three-stage pipeline, high-contrast typography, asymmetrical panels, and conventional controls where interaction clarity matters.

## Changed

- replaced all user-facing English copy and document metadata with Russian;
- added separate note and task workspaces with simplified statuses;
- added an always-visible AI pipeline and proposal decision panel;
- added confirmation, regeneration, retry, and task completion actions;
- replaced the generic report browser with an asymmetric workshop/dispatch-board design;
- added responsive project navigation and single-column mobile layouts.

## Verification

- Angular production build passed with a 197.64 kB initial bundle;
- desktop and 500 px mobile headless screenshots were inspected;
- DevTools measurement confirmed no horizontal document overflow at the headless browser's minimum viewport;
- UTF-8 AI output was verified by Unicode code points after regenerating the working draft;
- live API returned 131 new notes, 42 processed notes, one ready proposal, and zero tasks before human confirmation;
- full .NET/Core/MCP suite passed 16 tests and the protocol smoke test;
- npm and NuGet vulnerability scans found no vulnerable packages.

## Not checked

- a task card after confirming the real working proposal, because confirmation belongs to the human;
- touch interaction on a physical phone.

## Human confirmation

- [ ] Russian terminology and statuses are accepted
- [ ] The visual direction is accepted
- [ ] The first AI proposal is accepted or regenerated by the human
